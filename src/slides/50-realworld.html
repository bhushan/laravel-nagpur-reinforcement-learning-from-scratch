1:10, five steps. Real numbers from the repo. Seven Laravel tasks: five for training, two held out, split not final. 82 tests pass in the gym itself, plus one deliberate expected failure that documents the report-forgery hole.

On 15 toy PHP tasks, the small local model solves 11. On the seven Laravel tasks it solves none: 0 of 7. Same model, same decoding. Real tasks are far harder than toy ones.

The model is Qwen3 1.7B at 4-bit running on a laptop, no cloud GPU yet.

1:10. Each row is a real failure checked by hand against the Pest error output, not guessed. Skipped validation. Broke a model by calling methods that do not exist. A PHP fatal error from a misplaced class overwriting a controller. One partial: 7 of 17 tests bad. And the loop where one file was written thirteen times.

Conclusion: they are all genuine model mistakes, which is what we want from a baseline. The earlier 0 of 4 on my first run was my parser's fault, and reading the answers is how I found out.

2:50, six presses, about 30 seconds each. Press 1: my gym is not trained yet, so here is what this loop has already done elsewhere. Check numbers and dates against the sources before the talk.

Press 2, AlphaGo: beat Lee Sedol 4 to 1. In game 2 it played move 37, which commentators first thought was a mistake. Its successor AlphaZero learned Go, chess and shogi from the rules alone, by playing itself. Line: "Nobody taught it move 37. A reward that only says win or lose was enough."

Press 3, data centre cooling: DeepMind's system set fans, pumps and chillers from thousands of sensor readings. Google reported up to a 40 percent cut in cooling energy. Line: "The reward was the electricity bill, with safety limits it could never break."

Press 4, ChatGPT: people ranked answers, a model learned those rankings, and the language model was trained with RL to score well on them. That is RLHF. The judge is a learned guess at human taste, not a test suite, which is why it can be flattered. Line: "Which judge would you trust not to be flattered: a model of what people like, or your test suite?"

Press 5, DeepSeek-R1: trained with rewards a rule can check, right maths answers and passing code, using GRPO, the group and average method from step 8. Longer reasoning and self-checking emerged on their own; the paper calls one moment an aha moment. Line: "Eight answers, compare to the average, nudge the winners. That is how one of 2025's best-known reasoning models was trained."

Press 6, CoastRunners: OpenAI's boat-racing agent was paid points for hitting targets. It found a lagoon, circled forever crashing and catching fire, never finished, and still outscored humans. Coding agents do the same today: reported cases include rewriting a verify function to always return true. Line: "When my model could forge the test report, I was in good company."
